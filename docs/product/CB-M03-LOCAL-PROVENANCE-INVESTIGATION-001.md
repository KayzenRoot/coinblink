# CB-M03 · LOCAL Provenance Investigation Desk · P0

## Functional vertical
An offline editorial inspection experience layered over the three existing fictitious `example.test` source specimens. It adds:
- A bounded, immutable safety overview and per-source evidence-readiness reports.
- Native expandable accessible source reports with URL policy, licensing, evidence capture, digest and next-step labels.
- A two-source comparison with explicit same-source/invalid-selection rejection and no publishing authorization.
- Real Chromium and Node/VM tests for workflows, filters, keyboard, mobile responsive layout, WCAG A/AA, noindex and zero external egress.

## Explicit exclusions
No connector, ingestion, fetch, HTTP request, publication, customer analytics, provider secrets, storage, D1 changes, dependencies, workflows or real source licensing. Unknown rights always fail closed; the sample URLs are documentation labels, never contacted.

## Acceptance
Only the pre-existing three fully synthetic source records. Reports and comparisons cannot confer permissions or leak source metadata beyond the existing public demo. Contract tests ensure invalid IDs, incomplete rights, unavailable specimens, immutability and absence of live publication.

Require exact HEAD GitHub checks, M03 unit/Chromium, integration, build, SonarCloud zero new issues and duplication within gate, Socket and independent kayzenweb3 APPROVED. Keep main protected and request explicit separate owner authorization before squash merge. No deploy, spend, GEF or checkpoint modification.
